Edit a copy

Make a resized, watermarked or re-encoded copy of a photo. It all runs in your browser: nothing is uploaded.

    Size

    Made smaller to fit this photo: at the chosen size the text would be wider than the image.

    Format

    JPEG searches for the smallest file that scores 90 for similarity to the edit, out of 100 where 100 is identical. On a photo that is already a lossy web copy this often means a high quality and a large file. AVIF uses a fixed high quality. "Let the engine choose" picks the smallest file at a high but not identical quality, usually AVIF.

    This page edits the web copy the site publishes. The same recipe, run on the original file, makes the same edit from a better source. File sizes will differ: the CLI's optimize step uses a fast fixed quality, while this page searches for the smallest file that still looks like the edit.

    Colours: the CLI does not yet convert colour profiles. On an original in Display P3 (most iPhone photos) or Adobe RGB, it drops the profile without converting the colours, so the copy looks duller than this page's. Use the page's download for those photos, or convert the original to sRGB first.

    Run it in the folder named by your album's base: entry, which albums.yaml lists under bases: as a path relative to your site folder. Save the recipe below there as edit.toml. The photo's path in the command is relative to that folder.
